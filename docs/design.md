# nara 디자인 기준

밝은 바탕과 넓은 여백에 제품 사진과 둥근 브랜드 서체를 중심으로 구성합니다. 화면은 제품 목록, 상품 상세, 카트로 이어지며 추가 소개 배너·컨택트 화면·푸터를 만들지 않습니다.

- 로고와 주요 상품 제목은 Nara Display. 가격·옵션·수량·설명은 읽기 쉬운 Helvetica 계열 본문 fallback.
- 브랜드 팔레트: `#FFD300`, `#38B2FF`, `#19671B`, `#FE3B1F`. 작은 문구는 어두운 기본색을 쓰고 포커스는 초록으로 명확히 표시.
- 제품 이미지는 4:3 영역에서 contain. 관리자 원본 정렬과 variant 대표 이미지 연결을 사용.
- 데스크톱 상세는 이미지/정보 2열, 899px 이하에서는 이미지 다음 정보. 모바일 목록은 1열.
- 사진 탐색은 수동. 자동 회전 없음. 썸네일 레일은 edge fade 없는 Astryx Carousel, 확대는 Astryx Lightbox.
- Selector와 NumberInput은 얇은 테두리, 각진 모서리, 본문 서체. Portal 목록과 Lightbox도 같은 nara theme 사용.
- 장식용 애니메이션을 늘리지 않으며 이미지 확대 진입, 썸네일 스크롤, 선택·hover 상태만 강조. reduced-motion 설정 존중.

일반 구조와 반응형은 CSS로 유지합니다. 독립적인 컴포넌트 패키지나 앱 전체 상태관리 도구는 추가하지 않습니다.

# 구성 및 검수 상태

기준일: 2026-09-13. 이번 단계의 목표는 **미니멀한 메인 제품 리스트와 상품 상세의 로컬 프리뷰**입니다. Contact 폼·소개 배너·시각적 푸터는 사용자 요청에 따라 제외했습니다. 운영 공개와 Shopify 관리자 GitHub 연결은 다음 단계입니다.

## 연결

| 대상 | 값 | 상태 |
| --- | --- | --- |
| 공개 주소 | `store.nara.world` | 확인 |
| Shopify 도메인 | `9uqxpe-qv.myshopify.com` | CLI 인증 완료 |
| 기존 공개 테마 | Dawn 15.2.0 / `175690613075` | CLI 목록에서 live 확인, 수정·게시하지 않음 |
| 새 테마 이름 | Nara Studio | 테마 메타 정보 |
| CLI 개발 테마 | `206919729491` | development 역할, 로컬 서버 실행 확인 |
| GitHub 저장소 | `naralee-studio/store-nara-world` | 공개, `main`·`staging` 브랜치 |

실행은 `npm run dev`, 로컬 주소는 `http://127.0.0.1:9292`입니다. Shopify 직접 프리뷰 주소는 CLI 출력에서 확인합니다. 접근 링크는 공개 저장소에 기록하지 않습니다.

## 실제 확인

- 메인에서 두 제품의 사진·이름·현재 마켓 가격을 렌더링하고 상품 상세로 이동함.
- `family.`의 7개 옵션: 선택한 옵션, URL, 가격, 이미지, 수량 초기값이 함께 갱신됨. 한국 마켓에서 세트 5,980,000원, 파란 소파 2,600,000원 등 실제 표시 확인.
- `little family`의 단일 옵션 상세, 이미지, 가격과 상품 폼 확인.
- 로컬 장바구니: 보라색 테이블 추가 → 수량 1에서 2로 변경 → 합계 470,000원에서 940,000원으로 변경 → 삭제 → 빈 상태 확인.
- Shopify 직접 프리뷰: little family 추가 → Shopify 결제의 연락처·배송지 입력 화면까지 진입 확인. 개인정보 입력·결제·주문 생성 없이 테스트 장바구니를 비움.
- 로컬 프리뷰의 Shop Pay 전환에서는 HTTP 401을 관찰함. 결제 검수에는 Shopify 직접 프리뷰 사용.
- 보조 상품 목록의 가격 정렬, 검색 결과 2건 및 빈 결과 확인. 기본 검색·페이지·404 템플릿은 Skeleton의 보조 경로로 남아 있으며 메인 메뉴에 노출하지 않음.
- 390px 모바일 메인·상세·장바구니와 1440px 데스크톱 메인·상세 확인. 상세 썸네일은 한 줄 가로 스크롤이며 문서 전체의 가로 넘침은 없음.
- 최종 Theme Check: 41개 파일, 오류·경고 0. JavaScript 구문 검사 및 Git diff 공백 검사 통과. GitHub Actions의 같은 검사가 main·staging에 적용됨.

## 운영 테마 조사

운영 Dawn의 JSON 템플릿·섹션 그룹·설정을 `.local/live-reference`에 읽기 전용 참고용으로 내려받았습니다. 이 폴더는 Git과 Shopify 업로드에서 제외됩니다. 완전한 출시 백업은 아닙니다.

- 운영 상품 템플릿에서 가격·수량·구매 버튼 블록이 비활성화된 것을 확인함. `family.` 설명에도 `COMING SOON`이 있음. 새 기본 테마의 구매 폼을 실제 공개할 시점은 별도로 결정해야 함.
- 운영 테마의 `page.contact.json`은 확인했으나 이번 테마에는 사용자 요청에 따라 포함하지 않음.
- 운영 템플릿과 설정에서 `shopify://apps/` 블록 참조를 찾지 못함. 설치 앱 전체·필수 앱·비공개 메타필드까지 확인한 것은 아님.
- 영어 기본 UI와 현재 마켓 통화 표시를 사용함. 수동 국가·언어 선택 UI와 번역은 이번 미니멀 구성에서 제외. 국가 선택 기능을 추가할 때 저장 및 페이지 이동 후 유지까지 다시 검증할 것.
- Dawn의 프랑스 홈 컨텍스트 오버라이드는 새 메인의 섹션 구성이 달라 복사하지 않음. 마켓별 콘텐츠 차이는 출시 전 재검토.

## 출시 전 다음 단계

1. 확정 디자인, 판매 개시 여부, 국가·언어와 필수 앱 결정.
2. 실제 상품별 템플릿·메타필드 및 필요한 앱 블록·임베드 확인. 품절·재고 경계·배송·할인·실제 주문은 별도 검수.
3. `npm run dev:sync`로 편집기 설정의 로컬 동기화 검증.
4. Shopify 관리자에서 `staging` 연결 미공개 테마 생성, 코드 반영과 관리자 설정 커밋 왕복 확인.
5. 별도 `main` 연결 테마 생성, 출시 커밋·최신 설정·완전한 출시 사본과 기존 Dawn 복구 대상을 확인.

이번 작업은 `prepare`이며, 출시 준비 전체가 완료된 상태로 보고하지 않습니다.

## 푸터와 개인정보 안내

테마에서 푸터와 해당 Privacy policy 링크를 제거했습니다. Shopify 관리자에 저장된 정책, 쿠키 동의 설정, Shopify 결제 화면은 수정하지 않았습니다.

푸터 제거가 개인정보 고지 의무까지 없애지는 않습니다. 공개 전 사업자 소재지·판매 대상국·실제 데이터 수집에 맞춰 정책을 쉽게 찾는 경로와 수집 시점의 안내를 확인해야 합니다. 결제 화면의 정책 링크만으로 모든 방문자에 대한 안내가 충분하다고 판단하지 않습니다. 참고: [CNIL 투명성 안내](https://www.cnil.fr/fr/conformite-rgpd-information-des-personnes-et-transparence), [Shopify 정책 링크](https://help.shopify.com/en/manual/checkout-settings/refund-privacy-tos).
